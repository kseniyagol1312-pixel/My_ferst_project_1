# Тестирование

Автотестов в репозитории нет. Ниже чек-лист ручной приемки по критериям завершенности из ТЗ и сценарий смоук-теста.

Перед проверкой: меню «⋯» → «Восстановить демоданные» → «Восстановить».

## Смоук-тест через Playwright

Прототип при разработке проверялся скриптом на Playwright (headless Chromium). Минимальный пример:

```js
// smoke.js — запуск: node smoke.js (нужен пакет playwright)
const { chromium } = require('playwright');
const path = require('path');

(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage({ viewport: { width: 1400, height: 900 } });
  const errors = [];
  page.on('pageerror', e => errors.push(e.message));

  await page.goto('file://' + path.resolve(__dirname, 'index.html'));
  await page.evaluate(() => localStorage.clear());
  await page.reload();

  const rows = await page.$$eval('#cand-table tbody tr', r => r.length);
  console.assert(rows === 3, 'ожидалось 3 кандидата');

  await page.click('text=Диана Ким');
  await page.click('.d-tab[data-v=eval]');
  await page.click('[data-act=edit-eval][data-crit=c3]');
  await page.selectOption('#f-score', '2');
  await page.selectOption('#f-source', 'Тест');
  await page.fill('#f-fact', 'Кейс по воронке 12/30');
  await page.click('.m-foot [type=submit]');
  const stats = await page.$eval('.d-stats', e => e.innerText);
  console.assert(stats.includes('73%') && stats.includes('55%'), 'пересчет Fit/Coverage');

  console.log(errors.length ? errors : 'OK');
  await browser.close();
})();
```

Скрипт рассчитан на запуск из корня репозитория.
