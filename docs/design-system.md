# Дизайн-система

Визуальный стиль — спокойный профессиональный SaaS: светлый фон, белые поверхности, тонкие границы, без градиентов, glassmorphism, фото и декоративной графики. Главный акцент — матрица, проценты покрытия, статусы доказательств и факты.

Только светлая тема (`color-scheme: light`): темная тема исключена ТЗ.

| Токен | Значение | Назначение |

| `--text` | `#0F172A` | Основной текст |
| `--muted` | `#64748B` | Вторичный текст, подписи |

| `--border` | `#E2E8F0` | Границы |

| `--ok` / `-soft` / `-line` | `#0F766E` / `#E6F4F1` / `#A7D7CF` | Подтверждено, оценки 4–5, «Сильное соответствие», «В бюджете» |

## Типографика

- Шрифт: Inter (Google Fonts, 400/500/600/700). Запасной стек: `ui-sans-serif, system-ui, -apple-system, Segoe UI, Roboto, Arial`.
- Базовый размер 14 px; заголовок вакансии 18 px; цифры показателей 22 px.
- Подписи-ярлыки (`.h-label`): 11 px, uppercase, разрядка 0,06em.
- Числа в колонках выравниваются через `font-variant-numeric: tabular-nums` (класс `.num`).

## Форма

- Радиус карточек 12 px (`--r-lg`), элементов 8–10 px.
- Тени очень легкие (`--shadow`); выраженная тень (`--shadow-lg`) только у панели, модальных окон и уведомлений.

## Адаптивность

| Ширина | Изменения |
|---|---|
| ≤ 1100 px | Панель 86% ширины; сводка и карьерные факты в 2 колонки |
| ≤ 760 px | Панели на всю ширину; показатели 2×2; формы в одну колонку; вкладки навигации растягиваются на всю строку; название вакансии в навигации скрыто |

Боковые отступы: `max(16px, env(safe-area-inset-*))`. Страница не прокручивается горизонтально; широкие таблицы прокручиваются в своих контейнерах (`.tbl-wrap`, `.mx-wrap`).
