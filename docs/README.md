# Candidate Evidence Matrix — техническая документация

Демонстрационный прототип B2B HR-tech продукта для рекрутера. Помогает собирать данные о кандидатах из резюме, интервью и тестов, оценивать их по единым критериям вакансии, видеть подтверждения оценок и сравнивать финалистов.

Система **не принимает решение о найме**. Во всех итоговых блоках выводится подпись:
«Система структурирует данные и помогает сравнивать кандидатов. Решение принимает человек».

> **Не программист?** Начни с файла [00-start-here.md](00-start-here.md): там все объяснено простыми словами.

## Быстрый старт

1. Открыть `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari). Сборка, сервер и зависимости не нужны.
2. При первом открытии автоматически загружаются демоданные: вакансия Senior Product Manager и три кандидата.
3. Все изменения сохраняются в `localStorage` браузера. Сброс: меню «⋯» → «Восстановить демоданные».

Единственный внешний ресурс — шрифт Inter с Google Fonts. Без интернета страница работает на системном шрифте.

## Ключевые принципы

- Один файл `index.html`: HTML + CSS + JavaScript без фреймворков и сборки.
- Нет backend, базы данных, авторизации, API, интеграций и AI-вызовов.
- Нет загрузки файлов: кнопки загрузки — информационные заглушки с бейджем «Следующий этап».
- Не собираются и не оцениваются возраст, фото, пол, национальность, семейное положение, внешность, мимика, голос, эмоции.
- «Нет данных» — отдельное состояние, а не нулевой балл.
