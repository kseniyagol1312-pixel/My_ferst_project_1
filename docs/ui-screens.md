# Экраны и сценарии

## Общая компоновка

- **Верхняя навигация** (закреплена): название «Candidate Evidence Matrix», бейдж Demo, вкладки «Кандидаты / Матрица / Сравнение», название вакансии, меню «⋯» с пунктом «Восстановить демоданные».
- **Шапка вакансии** на каждом экране: название, статус, кнопка «Настроить критерии», подразделение, формат, бюджет, число кандидатов, кнопка «+ Добавить кандидата».
- **Правая панель** (около 70% ширины): карточка кандидата. На экранах уже 760 px занимает всю ширину.
- **Компактная панель** (440 px): детали ячейки матрицы.
- **Модальные окна**: все формы и информационные окна.

## Экран «Кандидаты»

1. Четыре показателя: кандидатов, финалистов (этапы «Интервью с менеджером» и «Финальное интервью»), средний Fit Score (только по кандидатам с Fit), среднее покрытие данных.
2. Панель инструментов: поиск по имени и должности, фильтр по этапу, «Сравнить выбранных (N)», «+ Добавить кандидата».
3. Таблица: выбор, кандидат (инициалы, имя, предварительный статус, предупреждение при недостатке данных), должность, этап, Fit Score, Evidence Coverage, ожидания, бюджет, «Открыть».

Клик по строке или кнопке «Открыть» открывает карточку. Чекбокс отмечает кандидата для сравнения. Кнопка «Сравнить выбранных» активна только при 2–3 выбранных. Четвертого кандидата выбрать нельзя: появляется уведомление.

## Карточка кандидата

**Шапка:** инициалы в нейтральном круге, имя, должность, выпадающий список этапа (смена сохраняется сразу), предварительный статус, Fit, Coverage, ожидания, бюджет, кнопка закрытия.

| Вкладка | Содержимое |
|---|---|
| Обзор | Контакты, локация, источник, дата выхода, ожидания, комментарий; карьерная история (компания, должность, период, длительность, достижение) и 4 карьерных факта; заглушка «Загрузить резюме PDF/DOCX»; текст резюме; кнопка «Редактировать» |
| Оценка | 9 карточек критериев: название, вес, бейдж «Обязательный», оценка, статус, источник, факт, комментарий, вопрос для проверки, «Изменить». Цветная полоса сверху по `tone()` |
| Интервью и тесты | Карточки интервью и «+ Добавить интервью»; таблица тестов с процентом и «+ Добавить результат»; заглушки «Загрузить транскрипт» и «Загрузить отчет тестирования» |
| Сводка | Статус, Fit, Coverage, бюджет, сильные критерии, риски по обязательным, критерии без данных, вопросы; кнопки «Сравнить» и «Скопировать сводку»; подпись о решении человека |

**Кнопка «Сравнить» в сводке** добавляет кандидата к выбору. Если выбранных стало 2 или 3, панель закрывается и открывается экран «Сравнение». Если выбран только он, показывается подсказка выбрать еще одного.

## Экран «Матрица»

Строки: критерии (все или только обязательные), затем Fit Score, Evidence Coverage, зарплатные ожидания, соответствие бюджету, предварительный статус. Столбцы: критерий и по одному на кандидата. В шапке столбца есть имя (открывает карточку), должность, этап и чекбокс «К сравнению».

| Режим | Что в ячейке |
|---|---|
| Баллы | Оценка и статус доказательности |
| Доказательства | Статус и источник |
| Риски | Тип риска (несоответствие, противоречие, нужно проверить, нет данных); ячейки без риска приглушены |

В каждой ячейке есть точка-индикатор: залитая, если записан факт или цитата, и пустая, если нет. Клик по ячейке открывает компактную панель с деталями и кнопкой «Изменить». После сохранения обновляются матрица, итоговые строки и панель.

Первый столбец и строка заголовков закреплены (`position: sticky`). Таблица прокручивается внутри своего контейнера, на мобильных по горизонтали.

## Экран «Сравнение»

- При 0–1 выбранных показывается список всех кандидатов с чекбоксами и подсказкой (пустого экрана нет).
- При 2–3 выбранных: карточки кандидатов (этап, статус, Fit, Coverage, ожидания, бюджет, предупреждение, «Открыть карточку», крестик «убрать из сравнения»), затем секции:
  ключевые сильные стороны, профессиональные критерии, поведенческие критерии, подтвержденные риски, данные, которых не хватает, вопросы для следующего интервью.
- Победитель автоматически не выбирается, об этом говорит информационная плашка.
- Кнопка «Вернуться к матрице».

## Формы и валидация

| Форма | Обязательные поля | Прочие правила |
|---|---|---|
| Кандидат (добавление и редактирование) | Имя и фамилия, текущая должность | Email проверяется по шаблону, если заполнен; ожидания — неотрицательное число |
| Оценка критерия | Оценка; при оценке 1–5 также источник и факт | При «Нет данных» поля статуса, источника и факта скрываются, доступны комментарий и вопрос |
| Интервью | Тип, дата, интервьюер, вопрос | Оценка необязательна. Дата по умолчанию — сегодня |
| Тест | Название, дата, результат, максимальный балл | Максимум > 0, результат ≤ максимума. Процент считается при вводе |

Ошибки показываются красным текстом под полем, фокус ставится на первое ошибочное поле.

## Уведомления (toast)

Показываются 2,8 секунды в правом нижнем углу: «Кандидат добавлен», «Данные кандидата сохранены», «Этап обновлен», «Оценка сохранена · Fit X% · Coverage Y%», «Интервью добавлено», «Результат теста добавлен: N%», «Сводка скопирована», «Демоданные восстановлены», «Можно сравнить не более трех кандидатов».

## Заглушки «Следующий этап»

| Кнопка | Текст окна |
|---|---|
| Настроить критерии | В следующей версии рекрутер сможет создавать критерии, задавать веса и шкалы под каждую вакансию (плюс справочная таблица текущих весов) |
| Загрузить резюме PDF/DOCX | После подключения защищенного хранения и AI система сможет извлекать из резюме опыт, навыки и подтверждающие фрагменты. В демоверсии используется текст резюме |
| Загрузить транскрипт | Прикрепление транскрипта появится после подключения хранения; сейчас интервью вносятся вручную |
| Загрузить отчет тестирования | Прикрепление отчетов появится после подключения хранения; сейчас результат вносится вручную |

Ни одна заглушка не открывает выбор файла и не меняет данные.

## Клавиатура и доступность

- `Escape` закрывает модальное окно, затем меню, затем панель.
- `Enter` на строке таблицы кандидатов открывает карточку.
- У всех интерактивных элементов виден фокус. Кнопки-иконки подписаны через `aria-label`.
- Панели и окна имеют `role="dialog"` и `aria-modal="true"`. Уведомления объявляются через `aria-live`.
- Учитывается `prefers-reduced-motion`.
